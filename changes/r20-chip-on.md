# r20 chip-on detection (approved by 筑衡 10:10)

57c1b54 gave the composer chips the class `ds-toggle-button` (SP-CMP-010 / SP-CMP-039 name `.ds-toggle-button` on the composer toggle, so the class stays).
The tests read the chip state with a substring match on the class (`includes('on')` / `toHaveClass(/on/)`), and "button" contains "on", so an off chip read as on. The checks now use the whole token `classList.contains('on')`, which is stricter.
