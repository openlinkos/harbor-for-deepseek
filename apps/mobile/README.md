# Harbor for Android

Capacitor shell around the web app. The default is an on-device key. A server address is optional and uses a bearer token.

Build and signing: [docs/android.md](../../docs/android.md). 中文：[docs/android.zh-CN.md](../../docs/android.zh-CN.md).

`apps/mobile/www` is generated by `node scripts/prepare-mobile.mjs` and is not committed. The public site’s CSP is not the one inside that copy.
