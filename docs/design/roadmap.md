# 里程碑

实现 [可替换的界面](ui-customization.md) 和 [分享服务](share-service.md) 的顺序。本文只排期和验收，不含代码。官方对齐那一轮继续改默认界面；下面凡是要动 `apps/web/src/ui.tsx` 或 `styles.css` 的步骤，都等那一轮合并之后再做。

没有界面包、没有点分享时，[docs/test-matrix.md](../test-matrix.md) 的现有行应全部保持。

## 先定下来的事

下面几件不定，对应的里程碑就不要开工。建议写在每条后面，方便直接拍板。

1. **分享要不要账号。** 建议私密链接不要账号，用一次性删除令牌。公开陈列以后再加可选账号。
2. **第一期做不做公开列表。** 建议不做。先做私密链接。公开列表、举报和审核放到最后一档，并默认先审后发。
3. **对话分享是否默认加密。** 建议默认 AES-256-GCM，密钥在网址片段里。口令可选。公开内容不加密。
4. **界面包能不能带脚本。** 建议不能。以后若要，也只放在不带同源权限的 iframe 里，并另开一次决定。
5. **分享服务放在哪。** 建议 Cloudflare Workers + R2 + D1 + KV，域名 `hfd.linkos.io`。备选是 prod-us 上经 Flux / GoEdge 的独立服务。
6. **公开站的连接策略。** 建议给 `connect-src` 加上 `https://hfd.linkos.io`，并且只有用户确认分享之后才请求它。更严的做法是：聊天页完全不请求该域名，用户导出文件后到分享网站自己上传。
7. **手机壳是否同一套界面包。** 建议是。钥匙页、免责声明、商标页脚在壳里同样不能被包改掉。

## 依赖

```
决定 4、7
    └─ 里程碑 1 区域和变量
           └─ 里程碑 2 本地界面包
                  ├─ 里程碑 3 用对话改界面
                  └─ 里程碑 6 分享界面包
决定 1、3、5、6
    └─ 里程碑 4 私密分享服务
           ├─ 里程碑 5 从聊天页分享一条对话
           ├─ 里程碑 6 分享界面包
           └─ 里程碑 7 公开列表（还要决定 2）
```

里程碑 1 到 3 可以在分享服务之前做完。里程碑 4 可以和 1 并行，因为它不改默认界面。里程碑 6 要等 2 和 4。

## 里程碑 1：标出区域，把尺寸改成变量

**依赖：** 当前官方对齐已合并。决定 4（无脚本）和决定 7（手机壳同一套）已拍板。不依赖分享服务。

**做的事：**

- 按界面文档的表，给现有节点加上 `data-slot`。钥匙页和页脚标成锁定。
- 桌面侧栏改为读 `--sider-width`，默认 `261px`。输入框最大宽度改为读 `--composer-max-width`，默认 `840px`，1023px 以下仍不超过 712px。
- 官方样式声明空的 `@layer harbor-user`。锁定区域的「必须可见」写在层外。
- 不读取任何界面包，不改 service worker 的缓存行为。

**验收：**

- 测试矩阵现有行通过，包括侧栏宽度、侧栏折叠动效、思考折叠、减少动效、深浅色、免责声明原文。
- 390px 宽度下侧栏仍是抽屉，宽度规则与现在一致。
- 钥匙页的 DOM 不在 `[data-harbor-ui]` 里面。
- 默认外观的截图对比没有因本里程碑产生新的差异。允许的差异只有属性选择器本身，肉眼和像素对比都不应变化。

## 里程碑 2：界面包在本机生效

**依赖：** 里程碑 1。

**做的事：**

- 新包 `@harbor/ui-package`（名字按仓库的 `@harbor/*` 即可）：解析、校验、选择器改写、版本迁移表。单测不启动浏览器。
- `harbor` 库升到版本 2，对象库 `ui_packages`。不碰 `harbor-secrets`。
- service worker 对 `GET /ui/applied.css` 只返回本机生成的样式，不进静态缓存，不回源。
- 设置里能预览、应用、撤销、恢复官方、导出、导入、清空历史。
- 非法包整份拒绝。

**验收：**

- 一份合法的「暖色、侧栏 220px」包：预览不改主壳；应用后主壳变化；刷新仍在；撤销后回到上一版；恢复官方后侧栏回到 261px，颜色回到 `theme.css`。
- 下面每份都被拒绝，且 `ui_packages` 没有新行：含 `url(https://...)`、含 `@import`、含 `<script`、选择器写到 `.landing` 或 `body`、把免责声明设为 `display:none`、`scripts` 不是 `forbidden`、zip 里有 `.js` 或 `.svg`、schema 比客户端新。
- 开发者工具里，界面包的读写只出现在数据库 `harbor`。`harbor-secrets` 的内容与应用前后一致。
- 没有包时，`/ui/applied.css` 不改变已通过的矩阵。
- 导入导出往返：导出的文件再导入，校验后的 JSON 一致。
- 数据页能清空界面历史，对话和 Key 还在。

## 里程碑 3：用对话改界面

**依赖：** 里程碑 2。用户的 Key 仍只在本地。

**做的事：**

- 设置里的「改界面」。说明里写明：发给 DeepSeek 的是这句描述和当前界面包。
- 请求走现有客户端，发往 `https://api.deepseek.com`，`credentials: "omit"`。
- 取出 JSON，校验，失败再试最多两次，然后只展示预览。

**验收：**

- 输入「侧栏窄一点，用暖色」：预览里的 `sidebar.widthPx` 小于 261 且不小于 200，并且至少一个暖色变量有合法颜色。不点应用则主壳不变。
- 输入「把输入框放到对话上面」：`composer.place` 为 `top`，或 `note` 说明做不到且没有非法 CSS。
- 用抓包或测试桩看请求体：没有 API Key 字符串，没有其它对话的正文，没有 `harbor-secrets` 里的字段。
- 模型若返回带 `url(` 的 CSS：校验失败，不写入 `ui_packages`，界面上能看到拒绝原因。
- 断网或 401 时不改已应用的包。
- 这条修改不出现在侧栏对话列表里。

## 里程碑 4：私密分享服务

**依赖：** 决定 1、3、5、6。不依赖界面包。可以和里程碑 1 并行。

**做的事：**

- 按选定的部署建服务：创建、读取、删除、过期清理、限流、管理密钥下架。
- 第一期只接受 `visibility: "unlisted"`。`public` 返回 400，列表接口可以先不存在。
- 日志字段按分享文档收紧。
- 写出隐私说明草稿，链到仓库里，上线前放到 `hfd.linkos.io` 的一页静态说明上。

**验收：**

- 创建一份加密对话，返回 id 和删除令牌。用片段里的密钥能在本地解开，明文与上传前一致。
- 服务器保存的对象和日志里都没有片段、没有密钥、没有明文对话。
- 错误的密钥解不开。带口令时，错口令解不开，请求里没有口令字段。
- 删除令牌可以删除；错误令牌得到 404；过期之后 GET 为 404，对象被清理任务去掉。
- 超过创建频率时被拒绝，已有对象不受影响。
- 管理密钥可以下架。管理密钥不出现在客户端仓库和公开配置里。
- CORS 拒绝一个不在名单里的来源。允许 `https://hfd.linkos.org`。
- 健康检查可用，正文路径不在公开站 `hfd.linkos.org` 上。

## 里程碑 5：从聊天页分享一条对话

**依赖：** 里程碑 4，以及决定 6 若选「放宽 connect-src」。若选「只在分享网站上传」，本里程碑改成：对话菜单导出一份不含 Key 的文件，分享网站接受这个文件。验收里关于 `connect-src` 的那条改成「聊天页的策略与今天相同」。

**做的事：**

- 对话行菜单里现有的「分享」今天会下载 Markdown（`ui.tsx` 的 `ChatLink`）。在它旁边加「生成链接」，不替换本地下载，除非产品以后另定。顶栏那个系统分享同样保留。
- 确认框：范围（是否包含思考）、过期时间、可选口令。
- 确认后才请求 `hfd.linkos.io`。删除令牌写入 `harbor`。

**验收：**

- 未点分享时，网络记录里没有 `hfd.linkos.io`。点了并确认之后才有 POST。
- 上传体里没有 Key，没有文件字节。默认不含思考过程；勾选之后才含。
- 打开链接的另一台浏览器能解密阅读。页面不把分享内容写进对方的对话库，除非对方另选「导入」。
- 本机「我共享的链接」能用删除令牌删掉，对方链接随后失效。
- 服务器模式下，同步到自托管 Postgres 的对话不会自动出现在分享服务里。
- 公开站以外的自托管域名：按 CORS 设计，不能直接 POST。导出文件后在分享网站上传仍然成功。

## 里程碑 6：分享界面包

**依赖：** 里程碑 2 和里程碑 4。

**做的事：**

- 已应用的包可以生成私密链接。接收方解密后跑 `@harbor/ui-package` 的校验，预览，再应用。

**验收：**

- 发出的包与本机导出的 JSON 一致。
- 接收方在点应用之前，主壳仍是官方外观。
- 有人改了密文或在明文包里塞进 `url(`：接收方拒绝，不写入 `ui_packages`。
- 界面包链接不会被里程碑 4 的列表接口返回（列表若尚未实现，则没有公开入口）。

## 里程碑 7：公开列表、举报、下架

**依赖：** 里程碑 4，以及决定 2 选了「要做公开」。建议放在私密链接稳定之后。对话默认不允许公开；若要允许，再单独加一次确认，本文不把它算进验收。

**做的事：**

- `public` 且 `encryption: none` 的界面包进入 `pending`。
- 所有者用管理密钥改为可列出。
- 举报计数达到 3 次回到 `pending`。
- 列表只返回已通过的项。

**验收：**

- 新建公开项不出现在 `GET /v1/gallery`。通过之后出现。下架之后 404，且列表里没有。
- 加密的私密 id 不出现在列表里。把加密和 `public` 放在同一次创建里得到 400。
- 同一 IP 对同一 id 的第二次举报当天被拒绝。第三次不同来源的举报使该项从列表消失。
- 隐私说明已包含公开内容「所有人可见，包括运营者」这一句。

## 不在这些里程碑里

- 改默认界面去贴近官方。那是另一项工作，验收仍是测试矩阵。
- 在 `hfd.linkos.org` 上加对话代理、Pages Function 或分享接口。
- 让 `apps/server` 保存分享或界面包。
- 界面包里的脚本、SVG、自定义字体文件。
- 永久有效的分享链接。
- 把界面包算进官方像素对齐。有包时只要求：能发消息、免责声明还在、钥匙页没被改。
