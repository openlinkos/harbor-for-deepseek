# 里程碑

实现 [可替换的界面](ui-customization.md) 和 [分享服务](share-service.md) 的顺序。本文只排期和验收，不含代码。官方对齐那一轮继续改默认界面；下面凡是要动 `apps/web/src/ui.tsx` 或 `styles.css` 的步骤，都等那一轮合并之后再做。

没有界面包、没有点分享时，[docs/test-matrix.md](../test-matrix.md) 的现有行应全部保持。第一期只做网页。

## 已决定

1. **私密分享没有账号。** 创建时发一次性删除令牌。库里只存令牌的 SHA-256。
2. **第一期只有私密链接。** 公开列表以后再做，不进下面的里程碑 1 到 6。
3. **分享默认不加密。** 隐私靠 128 位随机 id、`noindex`、可选过期、可选口令。正文在服务器上是明文：拿到链接的人可以读，持有磁盘和备份的人也可以读。口令只挡住没有口令的访问者。
4. **界面包不能含脚本。** 只描述外观：设计变量、消毒后的 CSS、布局，以及少量位图。
5. **分享服务放在 prod-us。** Flux 仓库 `best/flux-k8s`，入口 GoEdge，域名 `deepapi.linkos.io`。Cloudflare 仅 DNS，CNAME 到 `70c9d096.quic.ing`，与 `deepapi.linkos.org` 相同。TLS 在新建的 GoEdge 站点终结，证书由 GoEdge 自动续期，源站是 prod-us 的 Ingress。存储是集群内的 Postgres 加上数据盘上的对象文件。限流在 GoEdge 和应用里各做一层。备份保留 7 天。
6. **聊天页在用户确认分享之后才连接 `deepapi.linkos.io`。** 内容安全策略写上这个域名，未确认时不发请求。

## 依赖

```
里程碑 1 区域和变量（网页）
    └─ 里程碑 2 本地界面包
           ├─ 里程碑 3 用对话改界面
           └─ 里程碑 6 分享界面包
里程碑 4 私密分享服务（prod-us）
    ├─ 里程碑 5 从聊天页分享一条对话
    └─ 里程碑 6 分享界面包
```

里程碑 1 到 3 可以在分享服务之前做完。里程碑 4 可以和 1 并行，因为它不改默认界面。里程碑 6 要等 2 和 4。公开列表不在这条链上。

## 里程碑 1：标出区域，把尺寸改成变量

**依赖：** 当前官方对齐已合并。不依赖分享服务。只改网页。

**做的事：**

- 按界面文档的表，给现有节点加上 `data-slot`。钥匙页和页脚标成锁定。
- 桌面侧栏改为读 `--sider-width`，默认 `261px`。输入框最大宽度改为读 `--composer-max-width`，默认 `840px`，1023px 以下仍不超过 712px。
- 官方样式声明空的 `@layer harbor-user`。锁定区域的「必须可见」写在层外。
- 不读取任何界面包，不改 service worker 的缓存行为。

**验收：**

- 测试矩阵现有行通过，包括侧栏宽度、侧栏折叠动效、思考折叠、减少动效、深浅色、免责声明原文。
- 390px 宽度下侧栏仍是抽屉，宽度规则与现在一致。
- 钥匙页的 DOM 不在 `[data-harbor-ui]` 里面。
- 默认外观的截图对比没有因本里程碑产生新的差异。允许的差异只有属性选择器本身，肉眼和像素对比都不应变化。

## 里程碑 2：界面包在本机生效

**依赖：** 里程碑 1。

**做的事：**

- 新包 `@deepapi/ui-package`（名字按仓库的 `@deepapi/*` 即可）：解析、校验、选择器改写、版本迁移表。单测不启动浏览器。
- `harbor` 库升到版本 2，对象库 `ui_packages`。不碰 `harbor-secrets`。
- service worker 对 `GET /ui/applied.css` 只返回本机生成的样式，不进静态缓存，不回源。
- 设置里能预览、应用、撤销、恢复官方、导出、导入、清空历史。
- 含脚本或 SVG 的包整份拒绝。

**验收：**

- 一份合法的「暖色、侧栏 220px」包：预览不改主壳；应用后主壳变化；刷新仍在；撤销后回到上一版；恢复官方后侧栏回到 261px，颜色回到 `theme.css`。
- 下面每份都被拒绝，且 `ui_packages` 没有新行：含 `url(https://...)`、含 `@import`、含 `<script`、选择器写到 `.landing` 或 `body`、把免责声明设为 `display:none`、`scripts` 不是 `forbidden`、zip 里有 `.js` 或 `.svg`、schema 比客户端新。
- 开发者工具里，界面包的读写只出现在数据库 `harbor`。`harbor-secrets` 的内容与应用前后一致。
- 没有包时，`/ui/applied.css` 不改变已通过的矩阵。
- 导入导出往返：导出的文件再导入，校验后的 JSON 一致。
- 数据页能清空界面历史，对话和 Key 还在。

## 里程碑 3：用对话改界面

**依赖：** 里程碑 2。用户的 Key 仍只在本地。

**做的事：**

- 设置里的「改界面」。说明里写明：发给 DeepSeek 的是这句描述和当前界面包。
- 请求走现有客户端，发往 `https://api.deepseek.com`，`credentials: "omit"`。
- 取出 JSON，校验，失败再试最多两次，然后只展示预览。模型只能改外观字段。

**验收：**

- 输入「侧栏窄一点，用暖色」：预览里的 `sidebar.widthPx` 小于 261 且不小于 200，并且至少一个暖色变量有合法颜色。不点应用则主壳不变。
- 输入「把输入框放到对话上面」：`composer.place` 为 `top`，或 `note` 说明做不到且没有非法 CSS。
- 用抓包或测试桩看请求体：没有 API Key 字符串，没有其它对话的正文，没有 `harbor-secrets` 里的字段。
- 模型若返回带 `url(` 的 CSS，或返回脚本：校验失败，不写入 `ui_packages`，界面上能看到拒绝原因。
- 断网或 401 时不改已应用的包。
- 这条修改不出现在侧栏对话列表里。

## 里程碑 4：私密分享服务

**依赖：** 无。可以和里程碑 1 并行。清单进 `best/flux-k8s`，不进本仓库的 `harbor-web`。

**做的事：**

- 按分享文档建命名空间 `harbor-share`、一个应用副本、自带的 Postgres、数据盘上的对象目录、作为源站的 Ingress。Cloudflare 上为 `deepapi.linkos.io` 建仅 DNS 的 CNAME，指向 `70c9d096.quic.ing`。GoEdge 上新建站点，单独证书，源站指向这份 Ingress。
- 创建、读取、口令打开、删除令牌删除、过期清理、两层限流、管理密钥删除、每日备份保留 7 天。
- 只接受 `visibility: "unlisted"`。不提供列表接口。
- 响应带 `noindex`。`robots.txt` 禁止抓取。
- 隐私说明放到 `deepapi.linkos.io`，写明正文是明文。

**验收：**

- 创建一份不加密、不设口令的对话，返回 128 位 id 和删除令牌。用这个 id 能取回与上传前一致的明文。
- 数据库里的删除令牌是 SHA-256，不是原文。日志里没有正文、口令、删除令牌和 `Authorization`。
- 响应含 `X-Robots-Tag: noindex, nofollow`。`/robots.txt` 禁止抓取。
- 设了口令时，`GET` 不返回正文；`POST /open` 口令正确才返回。错误口令连续 5 次后这一小时内不再尝试。
- 省略 `expiresAt` 的分享不过期。设了过期的分享到期后是 404，对象文件被清掉。
- 删除令牌可以删除；错误令牌得到 404。
- 超过创建频率或 GoEdge 的请求体上限时被拒绝，已有对象不受影响。
- 管理密钥可以删除。管理密钥不出现在客户端仓库和 Git 里的明文配置中。
- 备份目录在 `/data/storage/harbor-share/backups`，含明文，超过 7 天的被删掉。对象文件不在系统盘的 compose 目录里。
- CORS 拒绝名单以外的来源。允许 `https://deepapi.linkos.org`。
- `/healthz` 与 `/readyz` 可用。分享的路径不在 `deepapi.linkos.org` 上。
- `deepapi.linkos.io` 的 Cloudflare 记录是仅 DNS 的 CNAME，目标为 `70c9d096.quic.ing`。公网证书在 GoEdge 的新站点上，并设置为自动续期。集群 Ingress 是源站，不持有这张证书。

## 里程碑 5：从聊天页分享一条对话

**依赖：** 里程碑 4。

**做的事：**

- 对话行菜单里现有的「分享」今天会下载 Markdown（`ui.tsx` 的 `ChatLink`）。在它旁边加「生成链接」，保留本地下载。顶栏那个系统分享同样保留。
- 确认框写明正文会明文保存，并让用户选范围（是否包含思考）、过期时间（含「不过期」）、可选口令。
- 确认后才请求 `deepapi.linkos.io`。`connect-src` 在 `apps/web/src/csp.ts`、`apps/web/public/_headers`、`deploy/web/nginx/security-headers.conf` 三处一起加上这个域名。删除令牌写入 `harbor`。
- 数据页「我共享的链接」列出本机还存着令牌的项。

**验收：**

- 未点确认时，网络记录里没有 `deepapi.linkos.io`。确认之后才有 POST。
- 上传体里没有 Key，没有文件字节。默认不含思考过程；勾选之后才含。
- 另一台浏览器打开链接能读到明文。设了口令时要先输入口令。页面不把分享内容写进对方的对话库，除非对方另选「导入」。
- 本机「我共享的链接」能用删除令牌删掉，对方链接随后失效。
- 服务器模式下，同步到自托管 Postgres 的对话不会自动出现在分享服务里。
- 公开站以外的自托管域名不能直接 POST。导出文件后在分享网站上传仍然成功。

## 里程碑 6：分享界面包

**依赖：** 里程碑 2 和里程碑 4。

**做的事：**

- 已应用的包可以生成私密链接。接收方取到明文后跑 `@deepapi/ui-package` 的校验，预览，再应用。

**验收：**

- 发出的包与本机导出的 JSON 一致。
- 接收方在点应用之前，主壳仍是官方外观。
- 包里若被放进 `url(` 或脚本：接收方拒绝，不写入 `ui_packages`。
- 没有公开列表可以翻到这份包。

## 以后：公开列表

不在第一期。私密链接的 id、删除令牌和明文存储都保持不变。要做时再加列表、审核和下架的展示，并另写验收。

## 不在这些里程碑里

- 改默认界面去贴近官方。那是另一项工作，验收仍是测试矩阵。
- 在 `deepapi.linkos.org` 上加对话代理、Pages Function 或分享接口。
- 让 `apps/server` 保存分享或界面包。
- 用 Cloudflare Workers、R2、D1 或 KV 跑分享服务。
- 分享默认加密，或把口令做成连服务器也读不到正文的加密。
- 界面包里的脚本、SVG、自定义字体文件。
- Android / iOS 壳上的界面包和分享。
- 把界面包算进官方像素对齐。有包时只要求：能发消息、免责声明还在、钥匙页没被改。
